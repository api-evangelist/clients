# Clients (clients)

This is the index of API client, HTTP client, and API consumer tools repos being tracked by the API Evangelist network. The collection includes command-line HTTP clients, GUI desktop and IDE clients, language-native HTTP libraries, and API testing/consumption tools.

**APIs.json:** [apis.yml](https://raw.githubusercontent.com/api-evangelist/clients/refs/heads/main/apis.yml)

## Scope

- **Type:** Index
- **x-type:** topic

## Tags

API Clients, Clients, HTTP Clients, HTTP Libraries, REST Clients

## Network

This is a topic index aggregating API/HTTP client repos across the API Evangelist network. The full list of network entries lives in `apis.yml` under `network:` and includes GUI clients (Postman, Insomnia, Bruno, Hoppscotch, Thunder Client, Yaak, Restfox, Paw, Nightingale, Milkman, ReqBin, Firecamp, Kreya, ezy, REST Client), CLI clients (cURL, Curlie, HTTPie, xh, Wget, gRPCurl), language libraries (Axios, Got, HTTPX, node-fetch, OkHttp, Requests, RestSharp, Retrofit), and the API Dash IDE.
